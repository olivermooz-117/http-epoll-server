Hello from epoll server v0.5.2!

A lightweight HTTP/1.1 server built using C++17 and Linux epoll.

Features

  • Non-blocking TCP sockets
  • Linux epoll event handling
  • HTTP/1.1 GET and HEAD methods
  • Persistent Keep-Alive connections
  • 30-second idle connection timeout
  • Maximum 100 requests per connection
  • Static file serving and MIME types
  • Partial socket read and write handling
  • HTTP error responses
